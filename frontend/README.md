# NETRA Dashboard

React + Vite + Tailwind frontend for Project NETRA.

```bash
npm install
npm run dev
```

Open http://localhost:5173 — the dashboard auto-connects to:
- the **backend** at http://127.0.0.1:8000 (alerts & status)
- the **engine** at http://127.0.0.1:8001/live-feed and /live-feed-raw (live MJPEG)
